# lifemart-bar

Статус текущего заказа в [Жизньмарте](https://lifemart.ru) прямо в строке меню macOS.

Заказал с телефона — на ноутбуке видно, что происходит с заказом. Окна нет, иконки в Dock нет: только значок в строке меню, который меняется вместе со статусом, и меню с подробностями по клику.

| Статус | Значок |
|---|---|
| Нет активного заказа | 🍴 `fork.knife` |
| Принят | 🕒 `clock` |
| Собирают | 📦 `shippingbox` |
| Готов к выдаче | 🛍 `bag` |
| Везут | 🛵 `scooter` |
| Доставлен | ✅ `checkmark.circle` |

В меню: статус и сколько прошло времени, откуда и куда, состав, сумма, ссылка на заказ. В настройках можно выключить уведомления о смене статуса.

## Статус проекта

Ранний прототип. Интерфейс работает на демо-данных (**Настройки → Демо-статус**), подключение к API в разработке.

## Сборка

Нужны macOS 14+ и Swift 6 (хватит Command Line Tools, Xcode не обязателен).

```sh
./scripts/bundle.sh
open build/LifemartBar.app
```

Чтобы приложение было в «Программах», скопируйте `build/LifemartBar.app` в `/Applications`.

## Дисклеймер

Это неофициальный проект, он никак не связан с Жизньмартом. Приложение использует то же API, что и сайт lifemart.ru, от имени вашего аккаунта; API может измениться в любой момент, и приложение перестанет работать.

Токен авторизации хранится только локально. Не публикуйте HAR-файлы и токены: по ним можно получить доступ к вашему аккаунту.
