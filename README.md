# lifemart-bar

Статус текущего заказа в [Жизньмарте](https://lifemart.ru) прямо в строке меню macOS.

Заказал с телефона — на ноутбуке видно, что происходит с заказом. Окна нет, иконки в Dock нет: только значок в строке меню, который меняется вместе со статусом, и меню с подробностями по клику.

| Статус | Значок |
|---|---|
| Нет активного заказа | 🍴 `fork.knife` |
| Принят, собирают | 🕒 `clock` |
| Собрали | 📦 `shippingbox` |
| Везут | 🛵 `scooter` |
| Готов к выдаче (самовывоз) | 🛍 `bag` |
| Доставлен | ✅ `checkmark.circle` |
| Токен не подошёл | ⚠️ `exclamationmark.triangle` |

В меню: статус, когда привезут и сколько прошло времени, откуда и куда, состав, сумма. При смене статуса приходит уведомление, его можно выключить в настройках. Приложение опрашивает lifemart.ru раз в 30 секунд, пока заказ в работе, и раз в минуту, когда заказов нет.

## Токен

Приложение ходит в API от имени вашего аккаунта, поэтому при первом запуске ему нужны два заголовка из браузера:

1. Откройте [lifemart.ru](https://lifemart.ru) и войдите в аккаунт.
2. Откройте DevTools (⌥⌘I) → **Network** и обновите страницу.
3. Выберите любой запрос к `api.lifemart.ru` и скопируйте из **Request Headers** значения `authorization` и `X-Api-Key`.
4. В меню приложения: **Настройки → Ввести токен…**

Оба значения хранятся только в связке ключей этого Mac.

## Сборка

Нужны macOS 14+ и Swift 6 (хватит Command Line Tools, Xcode не обязателен).

```sh
./scripts/make-signing-cert.sh   # один раз
./scripts/bundle.sh
open build/LifemartBar.app
```

`make-signing-cert.sh` создаёт самоподписанный сертификат в отдельной связке ключей `lifemartbar-signing` (в системе ему не нужно доверять). Сборки, подписанные им, macOS считает одним и тем же приложением, поэтому доступ к токену в связке ключей не нужно подтверждать после каждой пересборки. Без сертификата `bundle.sh` подписывает сборку одноразовой подписью.

Иконка приложения рисуется кодом в `scripts/make-icon.swift`; после правок пересоберите `Resources/AppIcon.icns` командой `./scripts/make-icon.sh`.

Чтобы приложение было в «Программах», скопируйте `build/LifemartBar.app` в `/Applications`.

## Дисклеймер

Это неофициальный проект, он никак не связан с Жизньмартом. Приложение использует то же API, что и сайт lifemart.ru, от имени вашего аккаунта; API может измениться в любой момент, и приложение перестанет работать.

Токен авторизации хранится только локально. Не публикуйте HAR-файлы и токены: по ним можно получить доступ к вашему аккаунту.
